🎯 Number Guessor
A command-line number guessing game built in Python. The player sets a custom difficulty range and tries to guess a randomly generated number.

🎮 How to Play

Run the program
Set your difficulty by entering a max number (e.g. 100, 500, 1000)
Guess the randomly generated number
After each wrong guess, choose to keep guessing or stop
Try to beat your highscore!


✨ Features

Custom difficulty — player sets the max range
Attempt counter — tracks how many guesses each round
Highscore system — saves your best score across rounds
Play again option — without restarting the program
Input validation — handles out-of-range numbers


▶️ How to Run
Make sure Python is installed, then run:
python number_guessor.py

🧠 Concepts Used

random module
while loops and nested loops
break, continue, pass
Flag variables to control multiple loops
Range checking and input validation
float('inf') for highscore initialisation
