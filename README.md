🧮 Calculator
A menu-driven calculator built in Python with both Basic and Scientific modes.

🎮 How to Use

Run the program
Select Basic or Scientific mode from the menu
Follow the prompts to enter numbers and operations
Result is displayed, then returns to main menu
Select Exit to quit


✨ Features
Basic Calculator

Addition, Subtraction, Multiplication, Division
Division by zero error handling

Scientific Calculator

Factorial, Combination, Permutation
Square Root, Cube Root, Power
Log (with custom base)
Exponent (e^x)
Trigonometry — Sin, Cos, Tan (input in degrees)
Inverse Trig — asin, acos, atan (output in degrees)
Input validation for all operations (log rules, sqrt range, inverse trig range)


▶️ How to Run
Make sure Python is installed, then run:
python calculator.py

🧠 Concepts Used

Functions
math module
Nested menus
Input validation (mathematical rules)
while loops with break and return
Floating point rounding with round()
Radians to degrees conversion
